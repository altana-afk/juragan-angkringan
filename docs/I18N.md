# Bahasa (Indonesia & Inggris)

Game punya dua bahasa: **Bahasa Indonesia** (bahasa sumber) dan **English**. Pemain memilih di
**Pengaturan → Bahasa · Language**. Pilihan disimpan per perangkat (`juragan-angkringan:lang` di LocalStorage),
terpisah dari save permainan.

## Cara kerja

- Semua teks pemain ditulis dalam bahasa Indonesia dan dibungkus `tr()`:

  ```ts
  import { tr } from '../i18n/i18n';
  ctx.notify(tr('Harga {name} jadi {p}.', { name: recipe.name, p: formatRupiah(price) }));
  ```

  Teks Indonesia itu sekaligus **kunci** kamus Inggris di `src/i18n/en/strings.ts`:

  ```ts
  'Harga {name} jadi {p}.': '{name} price set to {p}.',
  ```

- Kata benda yang berubah tunggal/jamak di bahasa Inggris memakai bentuk `{ one, other, count }`:

  ```ts
  '{qty} porsi dikirim ke cabang{1}.': { one: '{qty} portion sent to the branch{1}.', other: '{qty} portions sent to the branch{1}.', count: 'qty' },
  ```

- Kata pendek yang artinya beda menurut tempat memakai `trc('konteks', 'teks')`. Contoh: tombol "Tutup" =
  *Close*, status cabang "Tutup" = *Closed* → `trc('status', 'Tutup')`, kuncinya `'status|Tutup': 'Closed'`.

- Data JSON (`src/data/*.json`) tidak diubah. Teks Inggrisnya ada di `src/i18n/en/data/<nama>.json` yang hanya
  berisi teks (nama, deskripsi, dialog, dll.). Saat mode Inggris, `localizeData()` menggabungkannya: per `id`
  untuk daftar ber-id, per urutan untuk daftar tanpa id. Angka & aturan selalu dari `src/data/`.

- Catatan pembaruan Inggris ada di `src/i18n/en/changelog.ts`, per versi.

- Bahasa dibaca sekali saat game dimuat. Mengganti bahasa menyimpan progres lalu memuat ulang halaman.
  `?lang=en` / `?lang=id` di alamat juga bisa dipakai (misal untuk tautan atau uji).

- Format Inggris: `formatRupiah` → `Rp1,500`, `formatRupiahShort` → `Rp1.25M` / `Rp75K`, `formatClock` → `17:00`,
  tanggal → `Mon, Jul 6`.

## Menambah atau mengubah teks

1. Tulis teks Indonesia di kode dengan `tr('…')` (teks literal, bukan variabel).
2. Tambah terjemahannya di `src/i18n/en/strings.ts` dengan kunci yang **persis sama** (placeholder `{…}` juga sama).
3. Data JSON baru (menu, upgrade, event, kabar, …): tambah entri ber-`id` yang sama di `src/i18n/en/data/`.
4. Naik versi: tambah entri di `src/data/changelog.ts` **dan** `src/i18n/en/changelog.ts`.
5. Jalankan `npm test`. `tests/i18n.test.ts` gagal jika ada teks tanpa terjemahan, terjemahan yatim,
   placeholder berbeda, data JSON yang belum diterjemahkan, atau changelog yang belum lengkap.
6. Cek di browser: `npm run build && npx vite preview --port 4173`, lalu `python tests/e2e/english.py`.
   Dengan `?debug`, `window.__i18nMissing()` di console menampilkan teks yang belum diterjemahkan.
